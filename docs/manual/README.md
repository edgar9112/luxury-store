## Convenciones del manual

- **Texto para el cliente:** explicaciones sin tecnicismos, con pasos numerados y capturas cuando aporten.
- **Bloques de aviso:** se usan para advertir de acciones delicadas (por ejemplo, borrar datos).
- **Importes:** todos los precios se muestran en **dólares estadounidenses (USD)**, con formato `$1,234.56`.
- **Estados:** ✅ disponible · 🚧 en preparación · ⏳ pendiente.

## Glosario rápido

| Término | Significado |
|---|---|
| **Producto** | Artículo a la venta (por ejemplo, un reloj). |
| **Variante** | Versión concreta del producto: talla y/o color. Tiene su propio stock. |
| **SKU** | Código interno único para identificar un producto o variante. |
| **Cupón** | Código de descuento que el cliente introduce en el checkout. |
| **Checkout** | Proceso final de compra: datos de envío y pago. |
| **Pedido** | Compra registrada, con su número, importe y estado. |
| **Stripe** | Pasarela de pago que procesa las tarjetas de forma segura. |
